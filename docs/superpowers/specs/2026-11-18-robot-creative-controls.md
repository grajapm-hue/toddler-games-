# Creative robot assembly controls

User correction supersedes v2.04: at canvas 100%, a newly dropped part must have half the visible width and height of its Stores picture. Source aspect ratio is preserved. Its initial landing scale is stored independently of editable size percentages; orientation changes do not rewrite existing designs. New drops use the current Stores layout.

Empty canvas drags pan without a Move canvas mode. A selected placed part gets a gently flashing dotted outline. The shared plus/minus buttons act on that selected part (Both/Width/Height); tapping empty canvas deselects and makes those buttons zoom the camera. Two-finger pan/pinch always controls the camera and clears selection. The toolbar explicitly names Canvas or the selected part. Part percentages are relative to its initial dropped size, with 25%-400% creative sizing. Camera 100% retains the original source reference basis.

Size, left/right rotation, Flip, Original, Grid and camera controls are visible above the canvas. No Tools popup or Move canvas toggle. Compact rows and shorter labels preserve canvas space. Original restores a part's dropped size/orientation, not its position. Magnetic joining preserves the child's independent size, turn and flip, including enlarged heads/hands/legs; fitting does not reset creative geometry.
