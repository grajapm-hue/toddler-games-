# SaNa Little Hands: welcome preview 01

This is a local design preview, prepared for discussion. Nothing has been pushed or deployed.

Repository: https://github.com/grajapm-hue/toddler-games-

## Try it

Open `welcome-preview.html`, or run `node serve.mjs 8777` and visit http://127.0.0.1:8777/welcome-preview.html.

Keep the folder together: Tap to play opens the existing self-contained `SaNa-Little-Hands-Prototype.html` beside the welcome page. The four activities and three levels are unchanged.

## This step

- Landscape welcome screen inspired by the existing MathMatrix model.
- SaNa monkey, yellow sun, colorful play shapes and gentle bobbing motion.
- Large Tap to play, secondary Install app, and About controls.
- Small reminder for grown-ups; optional information stays out of the play path.
- The landscape layout rotates when the device is held in portrait.
- Reduced-motion preference is respected.
- Install app explains that installation is planned for the Beta release. It does not claim the app is installed.

## Next, after feedback

Agree on the welcome screen first, then refine the activity home, then the activities one at a time. GitHub Beta deployment and later Main deployment are separate future steps after approval. Existing MathMatrix apps are separate from this repository.
